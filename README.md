# 🌐 Portfolio Website with CI/CD (AWS + GitHub Actions)

This project demonstrates a fully automated CI/CD pipeline for deploying a portfolio website using AWS and GitHub Actions.

---

## 🚀 Project Overview

- Built a personal portfolio website using HTML & CSS  
- Automated deployment using GitHub Actions (CI/CD pipeline)  
- Hosted website on AWS (S3 / CloudFront)  
- Implemented continuous integration and deployment for faster updates

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS  
- **Cloud:** AWS S3, CloudFront  
- **CI/CD:** GitHub Actions  
- **Version Control:** Git & GitHub  

---

## ⚙️ CI/CD Workflow

The CI/CD pipeline is implemented using GitHub Actions.

### 🔄 Workflow Steps:
1. Code pushed to GitHub repository  
2. GitHub Actions workflow is triggered  
3. Website files are validated and processed  
4. Automatically deployed to AWS S3  
5. Website updated without manual intervention  

> GitHub Actions allows automating workflows directly from the repository :contentReference[oaicite:1]{index=1}
